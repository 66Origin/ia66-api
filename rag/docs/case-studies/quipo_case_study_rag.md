# CASE STUDY — QUIPO | Application mobile de ticket de caisse numérique
**Agence :** 66 Origin  
**Client :** Michael, fondateur de Ticketless → renommé QUIPO  
**Type de projet :** Repositionnement stratégique, naming, branding, UX/UI design, développement application mobile, site web  
**Secteur :** RetailTech / GreenTech / Application mobile / Dématérialisation  
**Contexte :** Fin du ticket de caisse papier, alternatives cloud jugées non écologiques et intrusives sur les données personnelles

---

## PROBLÈME CLIENT

Michael, fondateur de la startup Ticketless, avait développé une technologie pour remplacer le ticket de caisse papier — devenu une aberration écologique. Le marché basculait vers des comptes clients et emails, impliquant du stockage serveur et une empreinte carbone numérique parfois plus lourde, ainsi qu'une logique de collecte de données intrusive.

**Problème central :** Comment dématérialiser un ticket de caisse sans cloud et sans collecte de données personnelles ?

**Enjeux identifiés :**
- Le nom "Ticketless" est dépendant d'un objet voué à disparaître — pas scalable ni mémorisable
- Les solutions existantes (email, cloud) ne sont pas réellement écologiques
- Les retailers collectent les données en échange du service — modèle contraire aux valeurs du produit
- L'adoption par les commerçants et les clients devait être immédiate et sans friction

---

## SOLUTION PROPOSÉE PAR 66 ORIGIN

Approche mobile-first : le smartphone fait tout. Le traitement est local, instantané, autonome — sans connexion obligatoire, sans serveur, sans email, sans échange de données.

**Repositionnement stratégique :** une solution vraiment écologique devait être locale, instantanée et autonome, respectueuse des données personnelles par design.

---

## PRODUIT : QUIPO

**Type :** Application mobile + site de recrutement commerçants  
**Technologie :** QR code enrichi, traitement 100 % smartphone, aucun stockage serveur

### Fonctionnement en caisse
1. Après paiement, un QR code enrichi est généré en caisse
2. Le client le scanne dans l'application QUIPO
3. Le ticket est décodé et traité directement sur le smartphone
4. Le ticket apparaît instantanément à l'écran
5. Vérifiable immédiatement dès la sortie de caisse

**Aucun serveur. Aucun email. Aucun échange de données. Le smartphone devient le coffre-fort du ticket.**

### Fonctionnalités de l'application mobile
- UX/UI centré simplicité
- Gamification : collection de tickets, points, promotions, fidélisation
- Canal de communication direct commerçants / clients
- Fonctionne sans connexion internet obligatoire

---

## NAMING — QUIPO

**Origine du nom :**  
Le quipu, chez les Incas, est un système de cordelettes multicolores utilisé pour gérer les stocks et la comptabilité d'un village — analogie directe avec la fonction du ticket (compter, vérifier, archiver).

**Raisons du changement :** "Ticketless" était dépendant d'un objet voué à disparaître, pas mémorisable ni international.  
**Qualités du nom QUIPO :** Court, mémorisable, international.
