## Le contexte

Dans notre concept store du Marais à Paris, Michael, fondateur de la startup Ticketless, nous présente une technologie destinée à remplacer le ticket de caisse papier, devenu une aberration écologique.
Mais le marché bascule vers des comptes clients et des emails, donc vers du stockage serveur et une empreinte carbone numérique parfois plus lourde. Et surtout, vers une logique de collecte de data, souvent centrale pour les retailers.
Le vrai enjeu : comment dématérialiser un ticket de caisse sans cloud et sans collecte de données ?

## Notre conviction

Une solution vraiment écologique devait être locale, instantanée et autonome.
Quipo a défendu une approche “mobile-first” où le smartphone fait tout.
Une application mobile capable de :
\- Scanner un QR code enrichi en caisse
\- Décoder les informations d’achat
\- Afficher le ticket immédiatement
\- Fonctionner sans connexion obligatoire
\- Respecter les données personnelles, par design

## La solution : QUIPO

Nous commençons par repositionner la marque.
“Ticketless” est un nom dépendant d’un objet voué à disparaître.
Nous créons QUIPO.
Le quipu, chez les Incas, est un système de cordelettes multicolores utilisé pour gérer les stocks et la comptabilité d’un village.
Une analogie évidente : le ticket sert à compter, vérifier, archiver.
Un nom court.
Mémorisable.
International.
Nous construisons un univers complet : plateforme de marque, logo, identité visuelle, assets, supports de salons.

## La technologie : QR code enrichi, traitement 100% smartphone

Côté technologie, le principe repose sur un QR code augmenté inventé par Quipo et capable d’embarquer beaucoup d’informations.
En caisse, le QR code est généré.
Le client le scanne dans l’application.
Le traitement est réalisé sur le smartphone.
Aucun stockage serveur.
Aucun email.
Aucun échange de données.
Le smartphone devient le coffre-fort du ticket, sans intermédiaire.
Le ticket apparaît instantanément à l’écran, vérifiable immédiatement dès la sortie de caisse.

## FAQ - Quipo

### Qu’est-ce que Quipo ?

QUIPO est une solution de ticket de caisse numérique qui dématérialise les tickets via QR code enrichi, sans stockage serveur.

### Comment fonctionne QUIPO en caisse ?

Après paiement, un QR code est affiché. Le client le scanne et le ticket apparaît immédiatement dans l’application.

### QUIPO nécessite-t-il une connexion internet ?

Non.
Le traitement est local et peut fonctionner sans connexion.

### Les données clients sont-elles collectées et stockées ? 

Non.
Pas d’email, pas de cloud : pas de stockage serveur par défaut.

### Pourquoi avoir choisi le nom QUIPO ? 

Le quipu inca servait à gérer la comptabilité et les stocks. QUIPO reprend cette idée pour le ticket moderne.

### Le site QUIPO a-t-il été récompensé ?

Oui.
Le site de recrutement commerçants a été distingué, dont Awwwards, pour son design et son expérience utilisateur.
